# 鄭 光錫 (テイ コウシャク/ Tei Koushaku)

**株式会社シャイオス 代表取締役 CEO / IT経営コンサルタント / フルスタックエンジニア**

中小企業やスタートアップの経営者様へ向け、ビジネスとテクノロジーの両面から身近な相談相手として伴走します。

---

## 👤 プロフィール・経歴

* **ビジネスとITの基礎**: 同志社大学卒業後、青山ビジネススクールにてMBA取得。2021年、東京大学大学院の講座を修了。
* **現場での実務経験**: 大手ITコンサル会社にてDXプロジェクトに従事。
* **独立と現在**: 2021年9月に株式会社シャイオスを創業。中小企業のIT顧問やシステム受託開発、AI活用支援等を行っています。

## 🤝 大切にしている仕事のスタイル
